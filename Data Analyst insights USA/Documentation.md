# 📘 Data Analyst Career Insights USA

## 📊 Project Overview
This project analyzes data about **Data Analyst careers in the USA**, exploring salary patterns, experience levels, and job locations.  
The goal is to uncover trends that can help aspiring analysts understand the market and what affects salary levels.

---

## 🧰 Tools & Libraries Used
- **Python**
- **Pandas** – for data cleaning and manipulation  
- **Matplotlib** – for data visualization  
- **Seaborn** – for advanced and styled plots  
- **Jupyter Notebook** – for analysis and documentation

---

## 🗂 Dataset
The dataset contains information about data-related roles, including:  
- Job Title  
- Experience Level  
- Employment Type  
- Salary (in USD)  
- Employee Residence  
- Company Location  
- Remote Ratio  

---

## 🧹 Data Cleaning
- Handled missing values and removed unnecessary columns  
- Converted salaries into USD for consistency  
- Normalized text columns (e.g., job titles and locations) for easier grouping and comparison  

---

## 🔍 Exploratory Data Analysis (EDA)
The analysis aimed to identify:  
- Which job titles have the highest average salaries  
- How experience level impacts salary  
- The most common work setups (remote vs on-site)  
- Regional differences in pay and job opportunities  

---

## 📊 Data Visualization
Created visualizations using **Matplotlib** and **Seaborn** to show:
- Average salary by job title  
- Salary distribution by experience level  
- Job count by location  
- Remote vs on-site job ratio
